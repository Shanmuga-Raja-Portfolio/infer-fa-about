infer-FA: digital garment samples on a home-grown cloth simulator

Proprietary software by InferApps Tech PVT LTD. The source code is private. This page describes the project and what we're building.

Fashion still runs on physical samples: cut, sew, ship, try on, repeat. infer-FA aims to replace many of those rounds with digital samples that behave like the real fabric, for designers, technical designers, buyers, brand teams and manufacturers.

What we're building

  • Cloth simulation built in-house in Rust, driven by the same fabric properties that textile labs measure.
  • An open fabric description format so materials can be captured once and reused.
  • Patterns, seams and sleeves draped on simple body models.
  • Fit maps that show ease, strain and pressure across the garment.
  • Size grading and tech packs: pattern sheets and structured data, ready to hand over.
  • A local studio in the browser for building a range of styles.
